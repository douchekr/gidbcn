# 용어 사전 — 모하비 게코 사냥꾼

## 세계관
폴아웃 모하비 사막의 고독한 게코 사냥꾼. 주식 종목 = 게코(도마뱀).
사냥 = 게코를 탐색하고 잡아서 가죽을 벗겨 그 품질을 평가하는 일.

## 파이프라인 용어

| 용어 | 이모지 | 파이프라인 단계 | 설명 |
|------|--------|----------------|------|
| 탐색 | 🔍 | hunt (Gemini 추천) | 사막에서 게코를 찾는다 |
| 포획 | 📦 | collect (한투 API) | 게코를 잡아온다 (시세 수집) |
| 감정 | 🔬 | judge (Gemini 평가) | 가죽을 벗기고 품질을 따진다 |
| 양피 | 🦎 | judge 통과 | 양질의 가죽 확보 (judged 생존) |
| 척살 | 🗡️ | judge 미달 / 도태 | 가죽이 별로면 척살한다 |
| 황금 게코 | 🦎✨ | BOB 상위 7 | 최고 품질의 가죽. 트로피 |
| 독도마뱀 | ☠️ | blacklist | 방사능에 오염된 게코. 건들지 마라 (API 실패=영구, 척살=부활 가능) |
| 가죽 점검 | 🔄 | reeval (재평가) | 보관 중인 가죽을 재감정한다 |
| 포획금지 해제 | 🔁 | revive (패자 부활) | 독도마뱀의 포획금지를 해제한다 |
| 탄약 | 🔫 | budget (API 사용량) | 오늘 남은 총알 |

## 점수

| 용어 | 설명 |
|------|------|
| 사냥 매력 | hunt_score. Gemini가 매긴 탐색 점수 |
| 가죽 품질 | judge_score. Gemini 감정 점수 |
| 최종 등급 | score. 사냥 매력×weight + 가죽 품질×(1-weight) |

## 텔레그램 명령어

| 명령어 | 세계관 설명 |
|--------|------------|
| `/w run` | 사냥 출발. 모하비로 향한다 |
| `/w stop` | 은신처 복귀. 오늘은 여기까지다 |
| `/w ls` | 가죽 확보 현황 |
| `/w pending` | 탐색 중 먹잇감 |
| `/w bl` | 독도마뱀 목록 |
| `/w budget` | 오늘 탄약 |
