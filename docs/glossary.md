# 용어 사전 — 모하비 게코 사냥꾼

## 세계관
폴아웃 모하비 사막의 고독한 게코 사냥꾼. 주식 종목 = 게코(도마뱀).
사냥 = 게코를 포착하고 가죽을 벗겨 품질을 평가하는 일 전체를 광의로 일컫는다.

## 파이프라인 용어

| 용어 | 이모지 | 파이프라인 단계 | 설명 |
|------|--------|----------------|------|
| 사냥 | 🎯 | 전체 파이프라인 | 포착→가죽→척살/양피. 광의 |
| 포획 | 🔍 | hunt (Gemini 추천) | 게코를 발견해서 후보군에 넣는다 |
| 가죽 | 📦🔬 | collect + judge | 게코를 잡아 가죽을 벗긴다 (시세 수집 + 평가) |
| 가죽 | 🦎 | judge 통과 | 양질의 가죽 확보 (judged 생존) |
| 척살 | 🗡️ | BL행 | 품질 이하(점수 미달) 또는 기술적 오류(API 실패) |
| 황금 게코 | 🦎✨ | BOB 상위 7 | 최고 품질의 가죽. 트로피 |
| 독도마뱀 | ☠️ | blacklist | 방사능에 오염된 게코. 건들지 마라 |
| 가죽 작업 | 🔄 | evaluate (감정 사이클) | 가죽을 (재)수집하고 품질을 따진다 |
| 포획금지 해제 | 🔁 | revive (패자 부활) | 독도마뱀의 포획금지를 해제한다 |
| 탄약 | 🔫 | budget (API 사용량) | 오늘 남은 총알 |

## 점수

| 용어 | 설명 |
|------|------|
| 가죽 품질 | score. judge_score 그대로 저장 |
| hunt_count 보너스 | 도태 시 effective = score + ln(1+count) × weight |

## 텔레그램 명령어

| 명령어 | 세계관 설명 |
|--------|------------|
| `/w hunt` | 사냥 출발. 모하비로 향한다 |
| `/w stop` | 은신처 복귀. 오늘은 여기까지다 |
| `/w ls` | 포획 게코 (기본) |
| `/w ls pelt` | 가죽 확보 현황 |
| `/w bl` | 독도마뱀 목록 |
| `/w budget` | 오늘 탄약 |
| `/w clear gecko\|pelt\|bl` | 일괄 삭제 |
